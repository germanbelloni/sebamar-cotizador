# Sistema de pruebas y auditorías

El proyecto tiene 5 sistemas distintos:

1. Auditor de Consistencia de Cotizaciones
2. Auditor General
3. Tests Automáticos
4. Generadores Masivos
5. Validación Global del Sistema

3. Automatic Tests

   - Ruta: backend/tests/generators/
